# Кратко к защите

1. **Синхронность и AJAX.** Синхронный запрос блокирует вызывающий поток до ответа. Асинхронный позволяет продолжить работу и обработать ответ позднее. AJAX — обновление части страницы данными сервера без полной навигации; XML не обязателен. Здесь preventDefault отменяет отправку формы с переходом, $.ajax отправляет POST, await получает ответ, DOM обновляет таблицу. await приостанавливает async-функцию, а не весь интерфейс.
2. **jQuery.** Библиотека для выбора элементов, событий, DOM и запросов. Основные API: $(selector), .on(), .text(), .append(), $.ajax(). Аналог нашего запроса: $.ajax({url: '/fcgi-bin/app.jar', method: 'POST', data: {action:'check', x:0, y:0, r:2}, dataType:'json'}).done(render).fail(handleError). В проекте используется $.ajax с type: POST и локальной копией jQuery.
3. **SuperAgent.** HTTP-клиент с цепочками вызовов и Promise. Пример: await superagent.post('/fcgi-bin/app.jar').type('form').send({action:'check', x:0, y:0, r:2}); JSON доступен в response.body. Требует подключения библиотеки; в данном проекте не используется.
4. **CGI.** Интерфейс между веб-сервером и программой. Метод, длина и тип тела приходят через переменные окружения; тело — stdin; ответ с заголовками — stdout. Традиционно новый процесс на каждый запрос: простая изоляция, но дорогой запуск и отсутствие памяти между запросами.
5. **FastCGI.** Долгоживущий процесс получает запросы по протоколу FastCGI через TCP или Unix-сокет. Экономит время запуска, позволяет хранить состояние, отделяет приложение от Apache. Требует управления процессами, контроля памяти и корректной обработки повторных запросов. FastCGI и HTTP — разные протоколы.
6. **Java FastCGI.** FCGIaccept принимает очередной запрос; библиотека подменяет System.in/out и предоставляет request.params. Приложение читает ровно CONTENT_LENGTH байт, разбирает форму, валидирует данные, вычисляет попадание и выдаёт JSON в UTF-8 с длиной в байтах. Цикл обслуживает запросы последовательно. Apache работает со статикой и направляет динамику на Java. История живёт за пределами цикла запросов, по идентификатору cookie.
